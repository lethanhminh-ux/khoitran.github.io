# Tran Dang Khoi — Academic Portfolio V4

Multi-page, static HTML/CSS website. No build step, database or paid hosting required.

## Preview locally
Open `index.html` in Chrome/Edge. Use the top navigation to move between pages.

## Folder structure
- `index.html` — Home
- `about.html` — Personal story
- `research.html` — Research overview
- `leadership.html` — Leadership and community impact
- `awards.html` — Awards
- `beyond.html` — Beyond academics
- `projects/*.html` — Four individual project pages
- `css/style.css` — Shared design and responsive rules
- `js/main.js` — Small shared enhancement
- `assets/images/` — Website photographs

## Edit for free
Use Visual Studio Code (free) and the Microsoft Live Preview extension for instant browser preview.
For a true drag-and-drop visual editor, Silex is free/open source, but it is not a seamless editor for importing this existing hand-coded website. A rebuild may be necessary.

## Publish with GitHub Pages
1. Create a GitHub repository named `USERNAME.github.io` (or any repository).
2. Upload all files and folders, keeping the directory structure.
3. Go to Settings > Pages and deploy from branch `main`, folder `/ (root)`.
4. Wait for deployment and open the Pages URL. For a project repository, the URL will include the repository name.
